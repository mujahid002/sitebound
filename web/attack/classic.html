What happens

This is how most stores take stablecoins today: the checkout code holds the shop's address and the buyer copies it.

Copy the address, then inject the script and copy again. The script swaps the address on the page and in the clipboard. A buyer who checks only the first and last few characters can miss it; address-poisoning attackers pick lookalike addresses for exactly that reason.
